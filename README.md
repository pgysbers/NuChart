# NuChart

Package to automatically generate nuclear chart plots. This scripts are inspired from Heiko Hergert's plots to show the increase of ab initio methods over the years (see [link](https://doi.org/10.3389/fphy.2020.00379)). 

The data to generate the ab inito reach plot is taken from Heiko Hergert and is contained in /DATA/abinitiosummary.csv. This data is lacking the references in a lot of cases so if people want to contribute and help fill these out please make a pull request with the updated references. 

Also, if you see some results missing, please email me or make a pull request after adding those to the csv file.
